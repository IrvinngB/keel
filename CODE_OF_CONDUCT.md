# Code of Conduct

Keel adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and assume good intent. Critique ideas and code, not people.
- Welcome newcomers. A basic question is a sign the docs can improve.
- No harassment, insults, discriminatory jokes, sexualized language, or publishing
  anyone's private information.
- Maintainers may edit or remove comments, commits, issues and PRs that break these
  rules, and may temporarily or permanently ban contributors who repeatedly do.

## Scope

This applies in every project space (issues, pull requests, discussions, reviews) and
when someone represents the project in public.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@IrvinngB](https://github.com/IrvinngB), through a
[private security advisory](https://github.com/IrvinngB/keel/security/advisories/new)
or a direct GitHub message. Reports are reviewed promptly and kept confidential.
Enforcement follows the Contributor Covenant
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
